# Data Quality Assurance (QA) Portfolio

This repository contains a collection of data validation, cleaning, and quality assurance projects using SQL, Python (Pandas), and MS-Excel. These projects demonstrate my ability to ensure data integrity, reconcile messy datasets, and extract actionable business insights.

## 📁 [Project 1: Transaction Validation Analysis (SQL)](./Project_1_SQL)
* **Goal:** Identify duplicates, missing values, and anomalies in financial transaction data.
* **Tools:** SQL 
* **Outcome:** Queried raw data to flag missing records, duplicate IDs, and anomalous amounts, culminating in a clear Data Quality Summary Report.

## 📁 [Project 2: Automated Data Cleaning (Python)](./Project_2_Python)
* **Goal:** Programmatically transform a messy dataset into a reliable, standardized format.
* **Tools:** Python, Pandas
* **Outcome:** Wrote a script to standardize categorical data, coerce datetime objects, handle nulls, securely remove duplicates, and export a 100% reconciled CSV ready for downstream analysis.

## 📁 [Project 3: Expense Analysis Dashboard (Excel)](./Project_3_Excel)
* **Goal:** Analyze corporate expenses, spot outliers, and visualize trends.
* **Tools:** MS-Excel (PivotTables, Conditional Formatting, Lookup functions)
* **Outcome:** Built an interactive dashboard highlighting total spend by category and monthly trends, utilizing conditional formatting to automate anomaly detection.
